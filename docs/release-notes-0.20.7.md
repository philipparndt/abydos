# Abydos 0.20.7

## The project tree's refresh finishes

Pressing refresh in the project view no longer leaves the sweep running over
a tree that has already been re-read. It happened in folders that are not a
git repository.

## EXR images preview

`.exr` and `.hdr` files open as pictures, with a picture's icon in the tree.

## The pull-request list's sweep sits at the top

The waiting sweep in the pull-request list and the history pane runs along the
pane's top edge rather than under its controls.
