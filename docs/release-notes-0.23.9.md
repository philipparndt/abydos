# Abydos 0.23.9

## The Finder opens a `.vboard` file in Abydos

A `.vboard` now shows Abydos under *Open With*, and double-clicking one opens
it here when no other app claims the extension. With a vboard server named in
Settings ▸ Tools ▸ vboard it opens as a board; without one, the tab says so
and offers the file as text.
