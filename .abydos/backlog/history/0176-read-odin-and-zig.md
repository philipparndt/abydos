# Read Odin and Zig

`4e4507782` · 2026-08-02

Two grammars, and the extensions that reach them. A project written in a
language the editor cannot parse is a wall of one colour: no folds, no
structure pane, nothing to go to. Both were already in the examples — the zig
one has been there since the examples repository — and neither was readable.

Odin's blue and Zig's orange in the tree as well: a project of either is all
one extension, so the icon is what tells it apart at a glance.

The syntax tests cover them with samples in the shape real code takes: a
package clause, an import, a struct and a procedure for Odin; an @import, a
function and a print for Zig.
