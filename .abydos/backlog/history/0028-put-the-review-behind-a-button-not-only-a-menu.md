# Put the review behind a button, not only a menu

`ea5a2171d` · 2026-07-31

The agent review is the reason this app exists and it was reachable only
from the menu bar, which is where a feature goes to be forgotten. It now
has a seal icon in the left strip, above the terminal toggle, where the
bottom-docked tool windows live.

Both scopes sit behind the one control. They are the same action asked
of different code, and a strip this narrow cannot carry two icons that
would be told apart at a glance.
