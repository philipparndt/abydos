# Settings on a page, in the app's own colours

`3c48b6af1` · 2026-08-02

A preferences window is a box of the system's colours in front of a dark one,
sized to whatever fits and closed the moment anything else is wanted. As a
tab it takes the width it is given, the help under each setting has room to
be a sentence rather than a caption, and it can be left open beside the thing
being adjusted — which is the only way to tell whether the adjustment was
right.

The settings are now grouped as Editor, Terminal, Saving, Navigator and
Agent, named in one list that both the page and the old window read, so the
two cannot drift apart. ⌘, opens the page in the window being worked in; with
no window open the window still appears, because the settings have to be
reachable from an empty app.
