# Colour the whole titlebar while a program runs

`6bc155c2b` · 2026-08-01

The toolbar draws its items on glass and gives nothing to tint, so the
titlebar is transparent now and the strip behind it is one this app
paints. Hidden until something runs, so nothing changes when it has
nothing to say.

Commits that exist only here carry an up arrow in the history, measured
against every remote rather than the branch's upstream: a branch with no
upstream set may still have been pushed under another name.

Pressing debug while the debugger is open no longer closes the panel —
replacing the only session was asking the panel to go away, and the new
session arrived after it had gone.
