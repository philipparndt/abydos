# A backlog beside the project, and the requests it came from

`5090acc2d` · 2026-08-08

One file per task under `.abydos/backlog`, in the folder that says where it
stands: open, in-progress, completed. Moving a task is moving its file.

Committed, unlike the rest of `.abydos`, for the same reason `run/` is:
what is left to do belongs to whoever is working on the project rather
than to one machine.

Each open file carries what has already been ruled out, not only what the
task is. A task that has been looked at and not solved is worth more than
a title — the point is that the next person does not repeat the search,
and several of these have had a day of searching in them.

`history.md` is not a task list. It is every request made since the first
message of the project on 30 July, recovered from the Claude Code
transcripts, which are the only place the earlier ones survive — the task
store holds only this session's, numbered from 27. 327 substantive
messages out of 629, in order. What was *done* is better read from the
383 commits; this is for finding something asked for that quietly never
happened.
