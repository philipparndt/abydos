# Offer a scratch from the empty editor

`eedb82a62` · 2026-08-01

An empty window hides the tab strip, so the double-click that makes a
scratch has nothing to double-click on. "New Scratch File" now sits under
"Select a file to open" — the only coloured thing on an otherwise blank
page, which is enough to find it and quiet enough to ignore.

The capture run presses the button rather than calling what it calls, so
the control itself is what is covered.
