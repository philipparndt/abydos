# Number the open backlog from one, in the order it is worth doing

`c93d49402` · 2026-08-08

The numbers were whatever a global counter handed out — 36, 42, 50, 51,
52, 53, 56, 57 — which says nothing except how many other things had been
tracked first, on other projects among them.

Now 1 to 8, ordered: what stops somebody working, then what is missing,
then what is only untidy. So the kitty images that vanish and the blank
rows while Return repeats come before splitting the build into modules,
which nobody is waiting on.

Each file says at the bottom what it was called before, because two
commit messages cite the old numbers and immutable text cannot be
renumbered. That is the whole reason to keep the mapping — not
sentiment about the old list.
