# The tag says which session; now it can change it

`2edbad844` · 2026-08-03

Clicking `tmux · name ⌄` lists the server's sessions, with how many windows
each has and a tick beside the one on screen, and choosing one switches this
terminal's client to it — the same thing `C-b w` does, from the place that
was already telling you which session you were in.

"New Session…" at the bottom makes one in the project's directory and
switches to it, since a session worth starting from here is a session about
this.

A chevron on the tag, so it reads as something to press rather than a label.
