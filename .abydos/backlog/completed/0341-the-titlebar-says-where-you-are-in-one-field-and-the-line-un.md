# The titlebar says where you are in one field, and the line under it only says what is running

`821b45fa9` · 2026-08-07

The two pills read as somebody else's IDE: an initials square is JetBrains'
signature, and two matched grey chevrons said nothing about which one you would
press. One capsule replaces them — the project on the left, the branch on the
right, a hairline between, and the shortcut that will one day turn the whole
thing into a search. It stays two hit targets, so both menus still open by
pointing at the half they belong to.

A worktree keeps the repository's name and gains a chip: this window is ideai,
checked out at titlebar-capsule. Asked of git rather than read off the path,
since a worktree can be created anywhere, and resolved to the deepest worktree
containing the folder so a subproject inside one still lands on the right
answer.

Colour leaves the titlebar entirely. It was going to ride on the seam, but the
badge palette holds a green and a red, so one project would have sat there
looking permanently built and another permanently broken. The seam now means
one thing — a run — which is what lets it be absent when nothing is happening
and red when something failed. Colour stays in the switcher, where there is
more than one project on screen and it has something to tell apart.

The switcher's rows are one line instead of two: a rail on the leading edge
rather than a square, and the path right-aligned in a fixed face so the paths
form a column that can be read down. Twice as many projects fit. The three
commands that are not a project moved underneath them.

The branch menu offers the remote's own site next to Fork, named after the host
because an Enterprise install is git.example.com and calling it GitHub would be
a guess. Behind it: this branch, its commits, the pull requests, the repository.
⌥ copies the link rather than opening it.
