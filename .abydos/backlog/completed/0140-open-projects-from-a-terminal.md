# Open projects from a terminal

`22bf8e0e8` · 2026-08-01

`ideai` with nothing after it means here, which is what somebody standing
in a project directory wants; a directory opens as a project and a file
opens in the repository around it rather than in whatever folder it
happens to sit in. Through `open -a`, so a running instance takes the
path and raises its window instead of a second copy starting up.
