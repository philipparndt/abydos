# Say what it is now, not what it started as

`50cd709c8` · 2026-08-05

It began as the IDEA layout without the IDEA startup time, and the front page
still said so. What it claims now is two things, and neither is a layout: a
terminal that is where the work happens rather than a strip at the bottom of an
editor, and a program that runs — and stops on a breakpoint — inside the
cluster it belongs to, in about a second.

So the README and the page lead with those, the rest of an IDE follows them
instead of preceding them, and the comparison is gone from both. The last of it
was hiding in the font notice, which explained that the OFL grants its licence
"independently of the fact that ideai is an alternative to their IDE" — a
claim about the program, in a file about a licence.

The page itself is served from philipparndt/ideai-docs, because Pages will not
serve a private repository's site without a paid plan. `docs/index.html` is the
same file, kept here so it can be edited beside the code it describes.
