# A run tab looks like a run

`844dff1b4` · 2026-08-04

It had the same icon and colour as a shell, which is the one tab it is
never doing the same job as. A run now carries a play triangle, wears the
green the titlebar wears while it is going — the two are saying the same
thing, and the one in the corner of the eye is the tab — and keeps a
stopped mark afterwards, since a finished run is still not a shell and
its output is still worth coming back to.

The wash goes on after the tab's own background rather than before it,
which is where the first attempt put it: under the active tab's fill,
where nobody could see it.
