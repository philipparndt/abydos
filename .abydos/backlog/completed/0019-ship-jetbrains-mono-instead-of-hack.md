# Ship JetBrains Mono instead of Hack

`e1f2ac82f` · 2026-07-31

JetBrains Mono is SIL OFL 1.1 with no Reserved Font Name, so it can be
redistributed unmodified under its own name in an open-source project.
The licence grants this independently of the fact that ideai is an
alternative to their IDE, so the earlier concern about bundling it does
not actually block anything.

Third-party notices rewritten for the OFL: the Hack entry covered three
licences (MIT, Bitstream Vera, public-domain DejaVu) that no longer
apply.
