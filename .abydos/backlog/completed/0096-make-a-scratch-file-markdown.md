# Make a scratch file Markdown

`a68b9134a` · 2026-08-01

A scratch is usually notes with a bit of code in it rather than a program.
Markdown is the format that suits both: fenced blocks keep whatever
language is written on them, and prose in between does not come out
highlighted as if it were broken source.

It also means a scratch arrives with the rendered view already available,
which is what a page of notes usually wants to be looked at as.
