# Backlog

One file per task, in the folder that says where it stands. Moving a task is
moving its file: `open` → `in-progress` → `completed`.

Committed, unlike the rest of `.abydos`, for the same reason `run/` is: what is
left to do belongs to whoever is working on the project, not to one machine.

Each file starts with what the task is and, where it matters, what has already
been ruled out. A task that has been looked at and not solved is worth more
than a title — the point is that the next person does not repeat the search.
